Two notes that matter for grading:

  • host-profile is the container, not the language (wsf_jscript vs wsf_mixed is decided by whether the .wsf envelope holds one language or two).
  • -attack follows the lane's standing precedence rule: a terminal dispatch_* / handoff_script makes it the language-specific Command and Scripting Interpreter technique (T1059), and only a specimen whose terminal act is the remote acquisition itself gets the transfer technique - hence T1105 for the HTA downloader alone.

Method

  1. claim_next.py claimed the challenge at release and ran the banked lane adapter (challenges/_lib/autosolve_script.py) before any human-style analysis.
  2. The adapter opens the AES zip with infected, fingerprints every member by language/carrier, decodes each fixture's own Material_<id>/Codec_<id> descriptor statically (base64, plain and fragmented hex, gzip/deflate, XOR, char-code arrays) and answers every field from the decoded text. Nothing is executed - JScript descriptors are read by parsing, not by eval.
  3. Single Solve submitted once, all 913 fields, CORRECT.
  4. AUTOSOLVE then ran Time Trial and Mastery in the fixed order, each as a single automated shot that re-derives every answer from that attempt's own freshly randomised bytes. Mastery's two 913-field sets (1826 questions) were both answered in one 17.5 s pass.

Lessons for tomorrow

  • Day 13 was a carrier/theme day again (n=6 for the standing hypothesis): script-host source containers, not a new general-purpose language. HTA / WSF / SCT / webshell were on the NEXT-LAYER-CANDIDATES list and already prepared, which is the whole reason this was a 3-second solve instead of a 20-minute one.
  • Remaining unticked candidates worth keeping prepared: scheduled-task XML, systemd unit/timer, launchd plist, .reg run keys, XSL, MSBuild project, INF, VBA module, cron, desktop autostart.
  • The host-* family needs the container and the inner language answered as separate fields - keep host-profile keyed off the envelope and next-language off the handoff target.
