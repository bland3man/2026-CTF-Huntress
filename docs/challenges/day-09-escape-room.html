Escape Room

Challenge

  • Category: Warmups (Day 09). Game Master ID warmups-day-09.
  • Prompt: "These characters would very much like to escape."
  • Modes: Single Solve, Time Trial, Mastery - all CORRECT (3/3).
  • Answer form: one field, message, the fully decoded string from the assigned blob.

Artifacts

  • The assigned warmup blob for this attempt (dynamic per attempt).

Triage

Warmup-decode family. The title is the hint: the day's new layer is escape sequences - the "characters would like to escape" means the blob is an escaped encoding (e.g. backslash/hex/unicode/HTML escapes) to unescape, on top of the usual base/rot/xor chain.

Investigation

Solved by the generic adapter challenges/_lib/autosolve_warmups.py / decode_chain.py (not found in any source) at claim: it auto-peels the encoding chain (base64/32/45/58/62/85, hex, binary, octal, rot13/47, caesar, xor, zlib/gzip/bz2/lzma) and the escape-sequence layer, then submits the final non-empty decoded line as message.

Flags (GM completion tokens)

  • mastery Token3e881cefa3e58316fc88ddecfb5966bc

(Single Solve and Time Trial also CORRECT per the done-ledger; their per-mode tokens were not captured in the autosolve record.)

Minimal Reproduction

wsl python3 challenges/_lib/decode_chain.py <assigned blob> --slug then submit the final decoded line as message.

Lessons Learned

  • "Escape" in a warmup title = an escape-sequence decode layer. decode_chain handles it automatically; worth confirming the escape layer is registered for the warmup adapter so future escape-themed warmups stay zero-touch.
