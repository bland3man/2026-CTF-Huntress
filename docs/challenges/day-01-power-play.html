Triage

  • Classification: static PowerShell triage (malware_re / scripting_data). No execution is needed. The challenge text itself says the scripts "will never run".
  • Every specimen uses the same template:
    1. a Base64 blob is passed to [Convert]::FromBase64String;
    2. a $reconstruct scriptblock returns the bytes unchanged;
    3. the bytes are decoded as UTF-8 and passed to ConvertFrom-Json;
    4. the script returns an object built from single-letter keys (a, b, c, ...).
  • The intent comes from two places:
    • the $nativeTypes triad of .NET classes;
    • which keys appear in the decoded JSON.

Investigation

7z x -pinfected -oextracted power_play.zip
for f in extracted/*.ps1; do

4. Timed modes

  • Timed modes were run by an agent inside the AI Homebase VM, using a one-shot solver against the Game Master proxy. The steps were:
    1. op=start;
    2. download the artifact;
    3. AES-unzip it in memory;
    4. regex out the Base64 and decode the JSON;
    5. map the values to answers;
    6. submit.
  • Time Trial: the solver finished in 1.847 s (limit 8 s).
  • Mastery:
    • Two artifact sets were delivered one after the other (evidence-01.zip (challenge artifact, not published), then evidence-02.zip (challenge artifact, not published)). Measured processing was about 2.4 s.
    • The first Mastery op=start timed out on the client side even though the server had created the attempt. The solver recovered the attempt through the status call, renewed the expired timer, and completed it.
  • Local helper for the same job: scripts/triage.py decodes the blobs and classifies by the type triad.

Lessons Learned

  • Two indicators appear in both the collection and impact samples: the Login Data and Cookies browser targets, and the update-*.dat file. Tell the samples apart with the .NET type triad and their unique keys: Aes + .locked, ZipFile, or Process + wallet.
  • ATT&CK mapping follows the objective, not the mechanism. Browser credential theft is T1555.003 even when the data is zipped (not T1560).
  • The scenario answers come from a fixed list: resource_hijacking, synthetic_collection, synthetic_impact.
  • The zips use WinZip AES. Use 7z or pyzipper, not unzip or Python's stdlib zipfile.
  • For timed modes, one script should handle start, fetch, decode and submit in a single run. Answers typed by hand cannot meet an 8 s or 7 s limit.
  • On a client timeout, recover the attempt through the status call; don't start a new one blindly.
