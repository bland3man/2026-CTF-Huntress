Hex Appeal

Challenge

  • Lane: Warmups
  • Mode: Single Solve / Time Trial / Mastery
  • IDs: warmups-day-03 / warmups-day-03/time_trial / warmups-day-03/mastery
  • Prompt: "Sixteen seems like a perfectly reasonable number of fingers."
  • Objective: Decode the assigned blob(s) completely. Extract answer slugs in the specified format.
  • Answer Format: Three lowercase words separated by hyphens, followed by a hyphen and a two-digit number

Triage

  • Category: Encoding/Decoding (Hex, Base64, ROT13)
  • Hint interpretation: "Sixteen" = base 16 = hexadecimal
  • Primary approach: Multi-layer decoding (hex/base64/ROT13)
  • Key insight: Each challenge provides a different dynamic blob; answer format remains consistent
  • Mastery complexity: 13 separate encoded blobs with different encoding schemes

Investigation

Single Solve (untimed)

  1. Started the challenge and downloaded the assigned blob (224 bytes)
  2. Hex-decoded the blob to ASCII:
    • Input: hex-encoded bytes
    • Output: "Nice work decoding this warmup! To solve, submit this exact answer to the Game Master: nimble-scooter-boulder-88"
  3. Extracted the slug using regex: ([a-z]+-[a-z]+-[a-z]+-\d{2})
  4. Submitted: nimble-scooter-boulder-88
  5. Result: CORRECT

Time Trial (timed)

  1. Same approach as Single Solve
  2. Different dynamic blob with different answer: jovial-island-copper-93
  3. Submitted under the time deadline
  4. Result: CORRECT

Mastery (bundle, timed)

  1. Received 13 separate artifacts (one per answer field)
  2. Each artifact contained multi-format encodings:
    • Format 1: Base64-encoded message (starts with capital letters common in B64)
    • Format 2: ROT13-encoded text (identifiable by patterns like "guvf" = "this")
    • Format 3: Hex-encoded bytes
  3. For each artifact:
    • Decoded Base64 lines
    • Decoded ROT13 lines
    • Decoded hex lines
    • Extracted the slug from each using the standard pattern
  4. Submitted all 13 answers as a bundle
  5. Result: CORRECT

Lessons Learned

  1. Hint parsing: "Sixteen fingers" directly points to hexadecimal encoding
  2. Dynamic artifacts: Each mode has different assigned bytes; answers differ but format is consistent
  3. Multi-encoding: Mastery uses multiple encodings in a single blob (Base64, ROT13, hex)
  4. Bundle challenges: Mastery-mode challenges can have multiple answer fields, each requiring separate decoding
  5. Format stability: Once locked on Single Solve, the three-words-two-digit format applies to all modes
  6. Encoding detection:
    • Base64: Starts with A-Z, a-z, 0-9, +, /, =
    • ROT13: Look for common words rotated (e.g., "guvf" = "this")
    • Hex: All hex digits (0-9a-f)
