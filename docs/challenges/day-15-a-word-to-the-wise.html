A Word to the Wise (metadata-forensics, Day 15)

GM id: metadata-forensics-day-15-word-to-the-wise Question: Determine ooxml.external_relationship_targets for document-15-001.docx.

Solve

  • artifact_0.bin is a zip holding document-15-001.docx (an OOXML package, itself a zip).
  • Internal relationships (_rels/.rels) point at word/document.xml and docProps/core.xml (no TargetMode).
  • word/_rels/document.xml.rels holds two hyperlink relationships with TargetMode="External":
    • rId9 -> https://example.test/evidence/d87ca62c5bb7
    • rId10 -> https://example.test/control
  • Extractor: walk every *.rels part, keep Relationship elements with TargetMode="External", take Target.

Answer format (learned from the GM)

  • Document order ["https://example.test/evidence/d87ca62c5bb7","https://example.test/control"] was REJECTED.
  • Sorted (ascending) order was ACCEPTED: ["https://example.test/control","https://example.test/evidence/d87ca62c5bb7"]
  • Same convention held for Time Trial and Mastery (every set).

Timed modes

  • Time Trial and Mastery are bundles repeating earlier-day questions (jpeg, png, pdf, zip, pe, dotnet, msi, lnk) plus the new ooxml field and a synthesis question (filenames sorted by full-file SHA-256).
  • Fixes in challenges/_lib/autosolve_metadata.py:
    1. dispatcher regex: "Inspect x. Determine fmt.field for x." (re.search, not re.match)
    2. new field ooxml.external_relationship_targets (sorted JSON array)
    3. synthesis extractor: sha256 of each named file in the same zip, filenames in ascending digest order
    4. _sibling_member: filename questions chosen by wording (copy / roster / first evidence note); Mastery set2 'first evidence note' had been answered with the copy name and was rejected.

Result

Single Solve CORRECT, Time Trial CORRECT, Mastery CORRECT.
