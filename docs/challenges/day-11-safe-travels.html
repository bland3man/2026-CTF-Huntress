Safe Travels (Day 11, warmups)

Prompt: "Our usual base went on a URL-friendly vacation."

Hint: the pun points to base64 (the usual base) in its URL-safe variant (base64url, - and _ in place of + and /).

Artifact: a 147-byte text blob. Decoding it as base64 gives a single sentence: "Nice work decoding this warmup! To solve, submit this exact answer to the Game Master: <slug>". The slug is three lowercase words, a hyphen and a two-digit number. It differs per attempt, so each attempt's own bytes were decoded.

Method: autosolve_warmups.py (decode_chain peels the encoding and uses the slug format as an oracle). Results: Single Solve, Time Trial and Mastery all accepted CORRECT by the GM (1.2 s, 1.4 s, 3.3 s).

Lesson: nothing new needed; the existing base64/base64url decoder in the warmups adapter covered it.
