Fixture structure

Each .au3 file is the same three-part shape - a self-describing descriptor, exactly as every fixture has been since Day 6:

  1. A header comment ; HUNTRESS_ANALYSIS_V1:<TAG>-<blob>
  2. Global Const $descriptor_<id> = "<same blob>"
  3. Func build_plan_<id>() / Return $descriptor_<id> / EndFunc

Decoding the blob yields a pipe-separated k=v descriptor (v=3), which answers every field directly. The only variation is the <TAG> encoding of the blob, one per fixture:

TagEncodingobfuscation_profile
HEXplain hexplain_hex
B64base64base64
HB64hex of base64 (decode hex, then base64)hex_base64
FRAGhex in dot-separated 12-byte fragmentsfragmented_hex

FRAG is just unhexlify(blob.replace('.', '')); HB64 is b64decode(unhexlify(blob)). All four were already in the adapter's carrier table.

Pairing theme

The "matched set / which pairing is genuine" framing is the Day 9 stage-relationship graph carried forward, now expressed across the AutoIt pair: next_language plus stage_profile decide whether a hand-off is real (cross_language_handoff -> same_language/cross_language graph values) or merely "going through the motions". The three carried-over PowerShell scenario fields (resource-scenario, collection-scenario, impact-scenario -> resource_hijacking / synthetic_collection / synthetic_impact) and the Day 11 browser credential-store question (collection-attack -> the credential-store sub-technique, not the broader Data from Local System) were unchanged from yesterday.

Takeaways

  • Prepared candidate layers pay off: AutoIt was on the lane's candidate list and already in LANGS, so a brand-new language produced a 3-second three-mode sweep.
  • HB64 (hex-of-base64) and FRAG (dot-fragmented hex) are the two carrier spellings worth keeping: both appear only as the header tag, and both reduce to one line of Python.
  • The descriptor's attack= value always overrides the interpreter's own technique ID. T1059.010 is the right answer for "classify the AutoIt interpreter itself", never for "what does this specimen do".
