Day 24 - String Theory (warmups-day-24)

Lane: warmups. Agent: agent-3. All three modes CORRECT on the Game Master.

Prompt

"Count carefully. The comma knows where to stop." Answer id: message. Format: three lowercase words separated by hyphens, then a hyphen and a two-digit number (slug only).

Artifact

444-byte ASCII text, no newlines, e.g. 1:N,1:i,1:c,1:e,1: ,1:w,...,1:,,1: ,...

Each token is <count>:<char> (run-length), tokens joined by a comma. The trap is that <char> can itself be a comma (1:,), so a plain split(',') misreads the stream. Parse token by token with (\d+):(.) and require a comma separator (or end of text) after each token.

Decoded text: Nice work decoding this warmup! To solve, submit this exact answer to the Game Master: <slug>

Single Solve

Slug: jaunty-compass-mosaic-76. Derived locally from the saved artifact, then submitted through autosolve. Flag: Tokene19f67f33461d0495f9668cc6199061d

Time Trial

Same shape, new bytes per attempt; the same decoder solved it (1.5 s, ranked). Flag: Token8aa3508f528ca16417f8acb8f66303ac

Mastery

A zip of 118 blob-NN.txt (not found in any source) files. Each is ~25 numbered lines (NN<TAB>fragment), every line a different codec (base64, hex, binary, octal, percent, HTML entities, \u escapes, base32, morse, bacon, reversed text, UTF-16 hex, gzip/zlib base64, ascii85, ...). Today's new codec on the last lines is the same run-length count:char form, with a trailing comma on the fragment. Every blob decodes to the known sentence plus its own slug. Solved in 3.0 s. Flag: Token1c5a31959d0f9128d5b8d375950fb98b

What was fixed

challenges/_lib/autosolve_warmups.py: added _runlength_pairs() (strict whole-text parse) and registered it both in _direct_layers() (whole-blob) and candidates() (per-fragment, for the positional decoder). The first Single run failed with "no answer decoded for message" because no layer knew this codec. The first Mastery run opened its attempt, the set1 blob failed the known-sentence check, and nothing was submitted; the rerun after the fix used the existing attempt and was accepted.

Local helper: scripts/decode_string_theory.py (not found in any source) (standalone decoder for the Single artifact). Existing _test_autosolve_warmups.py (not found in any source) could not be used: it reads a Day 05 fixture that is not on disk.
