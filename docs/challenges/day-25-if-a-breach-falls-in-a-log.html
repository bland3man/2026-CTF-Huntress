Challenge prompt

"You broke in, and nobody wrote it down. Find the decisive moment the logs missed — if a breach falls in the forest, did it make a sound?"

No downloadable artifact; each attempt assigns live targets. SS and TT: one question (proof-1). Mastery: five targets (proof-1…proof-5).

Method summary

Single Solve + Time Trial (same audit flow)

  1. GET /api/clues to obtain the feature route + secondary audit route.
  2. POST {} to the feature route → response reports a completed protected_export and an export_id.
  3. GET the secondary (audit) route → find the event for that export (page_view in these targets).
  4. POST the secondary route with:
{
  "export_id": "<ID from export response>",
  "missing_event": "protected_export",
  "observed_event": "page_view"
}
  1. Submit the returned evidence as proof-1.

Lessons / faster-next-time

  • Start each mode first and use its assigned target URLs — these change per attempt.
  • Read the target's visible route inventory (/api/clues, robots.txt, home-page links) BEFORE guessing paths.
  • For the audit flow: copy the LIVE export_id + observed event from the response into the report request. Values are per-target, not reusable.
  • Session-based APIs: GET / first with a cookie jar, then hit the API.
  • SQL injection: confirm the schema via sqlite_master, THEN UNION with the right column count/paren context.
  • Mastery can be a MIX of vuln types — do not assume one exploit applies to all 5 targets.

Script

scripts/solve.py — dependency-free Python 3 proof collector. Supports:

python3 solve.py audit TARGET_URL      # audit-flow (SS/TT and MM target 5)
python3 solve.py archive TARGET_URL    # robots.txt + archive listing + .bak
python3 solve.py idor TARGET_URL       # case_session + /api/events + /api/incidents
python3 solve.py sqli TARGET_URL       # UNION injection
python3 solve.py lfi TARGET_URL        # ?doc= traversal
python3 solve.py mastery U1 U2 U3 U4 U5    # all 5 targets at once

The solver prints proofs; it does not submit to GM. autosolve.py submits.
