Mastery

The assigned artifact is a zip of 63 files (blob-NN.txt, one answer id setNN.message each). Each file has 13 numbered lines ("NN<TAB>data"). Every line holds one chunk of the same sentence ("Nice work decoding this warmup! To solve, submit this exact answer to the Game Master: <slug>"), and the encoding is fixed by line number:

1 base64, 2 rot13, 3 hex, 4 binary, 5 decimal, 6 octal, 7 percent, 8 HTML entities, 9 JSON \u escapes, 10 base32, 11 base64url, 12 reversed text, 13 Atbash.

Decode each line and concatenate the chunks (chunk boundaries fall mid-word and mid-slug, so the slug words are split across lines 11-13). The last word-word-word-NN in the text is the answer.

The generic autosolve peeler decoded lines independently and let its slug-regex oracle accept mis-decoded fragments (for example "quiet-gvzzhf-kyxxiv-23" = Atbash chunk not reversed/joined); it was submitted twice and scored incorrect (no variant spent: 256 untimed attempts remained). Solving locally from the real bytes fixed it: scripts/solve_mastery.py decoded all 63 files, one GM submit was CORRECT.

  • mastery flag: Token8fc369a0e37c8713a4b379719322c37d

Example: blob-01 -> quiet-summit-copper-23 (line 11 b64url "...er: quiet", line 12 reverse "-timmus-" -> "-summit-", line 13 Atbash "xlkkvi-23" -> "copper-23").

Scripts: scripts/solve_mastery.py, scripts/submit_mastery.py, scripts/mastery_blob.bin (the assigned mastery zip).
