Half a Turn

Warmups SSTTMM Modes reported CORRECT in this write-up

Challenge

  • Category: Warmups (Day 02)
  • Author: John Hammond, and Just Hacking Training
  • Prompt: "Thirteen steps forward. Funny how that works out."
  • Modes: Single Solve (2 pts, static) / Time Trial (3 pts, <1s dynamic) / Mastery (5 pts, 8 tasks <8s)
  • Artifact: half_a_turn.txt (108 B), downloadable from the challenge page or from the Game Master.

Triage

"Thirteen steps forward" = ROT13 (rotate each letter 13 places). A 13-place rotation is its own inverse, so "funny how that works out" (apply it again to undo). Pure FAST PATH — no VM needed for the analysis; the only VM touch is the Game-Master submit on the dynamic Time Trial / Mastery modes.

Investigation / Flag Recovery

  1. Fetch half_a_turn.txt (the assigned bytes).
  2. ROT13-decode the contents: 
    rot13 = lambda s: s.translate(bytes.maketrans(
    b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz",
    b"NOPQRSTUVWXYZABCDEFGHIJKLMNopqrstuvwxyzabcdefghijklm"))
print(rot13(open("half_a_turn.txt","rb").read()).decode())
  3. The decoded plaintext is the answer; submit it to the Game Master under the attempt's answer_id (or paste in the CourseStack lesson for Single Solve). For Time Trial / Mastery (dynamic, timed), run the decode start-to-submit in one deterministic pass per attempt.

Status

All 3 modes completed on Day 02 (3/3). Completion tokens auto-completed CourseStack via the Game Master; individual token values were not separately captured for this warmup (the solve is reproducible from the method above against any served instance).

Minimal Reproduction

Download the assigned half_a_turn.txt -> ROT13 it -> submit the decoded string under the attempt's answer_id via the Game Master. For timed modes, one deterministic start->download->rot13->submit run.

Lessons Learned

  • Title/prompt wordplay names the technique ("thirteen steps" = ROT13). Parse the pun first (triage RULE 3).
  • Warmups are FAST PATH + deterministic: the only cost is the GM submit (VM must be running to reach the Game Master over SSH, so batch it into the day's one VM-on burst).
