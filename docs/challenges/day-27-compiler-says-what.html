Compiler Says What (binary-reverse-engineering, Day 27)

Prompt: every compiler signs its work - compare the runtime and linker fingerprints across builds and name the toolchain, attributing this binary to its maker.

Method: static analysis via the framework's binary-RE lane solver (autosolve_binary through agent_solve_cid.py; per-CID working copy at challenges/Day 27/Compiler Says What/scripts/solve.py). Nothing was executed - headers, section names, symbol tables and HCFG config records were parsed from the artifact bytes alone (ELF via elf_info, PE/COFF/COMDAT via binary_facts, base64/raw HCFG scans via _hcfg_scan/_b64_hcfg). Single had 324 fields answered; Time Trial 324 (same shape, mutated bytes); Mastery 3564 across 5 sets.
