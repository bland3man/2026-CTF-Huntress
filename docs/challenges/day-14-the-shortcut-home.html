The Shortcut Home (metadata-forensics, Day 14)

Question: Determine lnk.target_path_windows for shortcut-001.lnk.

Approach

  • artifact_0.bin is a zip holding one Windows shell link (shortcut-001.lnk, 547 bytes).
  • Parsed the MS-SHLLINK structure by hand: header flags 0x97 (HasLinkTargetIDList, HasLinkInfo, HasName, HasWorkingDir, IsUnicode).
  • LinkInfo: LocalBasePath = C:\Windows\System32\cmd.exe, CommonPathSuffix empty. The IDList items (Windows / System32 / cmd.exe) agree.
  • Name string: "Huntress deterministic shell-link evidence 7E5EF87F23AC"; working dir C:\Windows\System32.
  • Target path = LocalBasePath + CommonPathSuffix.

Answer (GM-accepted)

C:\Windows\System32\cmd.exe

Tooling

  • New extractor challenges/_lib/lnk_meta.py (lnk.target_path_windows, lnk.local_base_path, lnk.working_dir, lnk.arguments, lnk.name, lnk.relative_path, lnk.icon_location), registered in autosolve_metadata.py (not found in any source).
