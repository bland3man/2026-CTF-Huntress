Category: mobile-android (Huntress CTF 2026 Day 03). Answer format: ANS- + 16 uppercase hex.

Investigation

The assigned APK contains assets/huntress_puzzle.json: {"schema":"huntress.mobile.puzzle.v1","day":3,"codec":"base64","data":"..."}. Base64-decoding data yields the backend answer code directly (the manifest/dex nested-Intent story is flavor). Same mechanic for Time Trial and each of the 3 Mastery deliveries; derived from each attempt's own APK bytes.
