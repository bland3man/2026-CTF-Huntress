Local Secrets (mobile-android, Day 11)

GM id: mobile-android-day-11-local-secrets

Result

Single Solve, Time Trial and Mastery were all accepted CORRECT by the GM, solved by the existing autosolve_mobile.py adapter (about 1.0 s, 1.3 s and 1.8 s).

Method

  1. Unzip the APK (6 members: manifest, classes.dex, certificate, assets).
  2. Read assets/huntress_puzzle.json. Today's variant: schema huntress.mobile.puzzle.v1, day 11, codec "xor", a base64 data string and an integer key (81).
  3. Base64-decode data, XOR every byte with the key, and the result is ANS- followed by 16 uppercase hex.
  4. Submit under answer_id "answer" (exact normalization).

Notes

  • The Android theme (local credential stores vs decoys) is flavour; the puzzle asset codec is the answer.
  • The xor codec with a single-byte key was already covered by autosolve_mobile.py (earlier days), so no code change was needed.
  • Timed modes are mutated per attempt; the adapter derives each answer from that attempt's own APK.
