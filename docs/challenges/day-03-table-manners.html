Table Manners

Challenge

Binary RE (Day 03, lane binary-reverse-engineering). Prompt: "A .NET binary is a database wearing a trench coat. Read the CLI metadata tables - methods, strings, signatures - and find where the configuration is stashed." GM id: binary-reverse-engineering-day-03-managed-configuration (single_solve / time_trial / mastery). 24 answer_ids per delivery (Mastery: 48, set1./set2. prefixed).

Artifacts

Password-protected zip (infected) holding d01--variant-N.elf (C), d02--variant-N.elf (C++ with .hcfg), d03--variant-N.dll (.NET) and its runtimeconfig.json.

Triage

Forensic-inventory questionnaire, same family as Day 01 "ELF Aware" and Day 02 "Mangled"; d01/d02 were the already-known public samples (same sha256 as Mangled), d03 is new.

Investigation

  • d01: ELF header + section/symbol tables parsed from bytes; recover_code = mov eax,0x1fa4; ret (8100).
  • d02: .hcfg = HCFG + ver + XOR key + len + CRC32 LE, payload single-byte XOR JSON (key 0x31, CRC 0x6149aa00).
  • d03: PE32 i386 .NET assembly, metadata version v4.0.30319. Config is a 379-byte <PrivateImplementationDetails> static array, XOR 0x41 -> JSON (campaign, domain, mutex, url, ...). Found by scanning for XOR of {"campaign".
  • Formats: reused Day 01/02 accepted spellings; new fields were found with the GM's partial-submit oracle (one field per submit, accepted+remaining vs incorrect): d03_analysis_format=pe_cli, machine=i386, section names include the leading empty string, symbols = all non-empty .symtab names in order, disassembly = ["mov eax, 8100","ret"].

Minimal Reproduction

scripts/solve_tm.py (compute from the attempt's own bytes) run on the Homebase VM with ctf_gm.py; scripts/solve_tm_m.py batch for Mastery.

Lessons Learned

  • Partial single-field submits are a per-field oracle; use them on the untimed Single Solve to lock unknown formats.
  • Timed modes: avoid long recon starts (deadline ~6s); GM rate-limits bursts (429) - add retry/sleep.
  • Pitfall: a flat full-batch incorrect in TT right after an expired attempt; per-field submits in a fresh attempt succeeded.
