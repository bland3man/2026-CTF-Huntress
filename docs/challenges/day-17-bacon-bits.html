Bacon Bits (warmups-day-17)

Layer: Baconian cipher (26-letter, a=0 b=1, 5 symbols per letter) whose plaintext letters A..P are hex nibbles (A=0 ... P=15), two letters per byte. Prompt: "Sixteen guests. Five little a's and b's apiece." (16 nibble values, 5-bit groups).

Single Solve

Artifact: groups of 5 a/b -> 0..15 -> pairs of nibbles -> ASCII "Nice work decoding this warmup! To solve, submit this exact answer to the Game Master: tidy-rocket-harbor-20". Answer: tidy-rocket-harbor-20. GM: CORRECT, flag Token40eac837c6737c720dad3d565a412dae.

Time Trial

Same shape. Answer: daring-blanket-coral-15. GM: CORRECT, flag Token666bb7f9a71444a07fcb98fe08024022.

Mastery
