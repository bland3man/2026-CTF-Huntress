Little Endian on the Prairie (metadata-forensics, Day 19)

GM id: metadata-forensics-day-19-little-endian-on-the-prairie

Task

Question: Determine elf.e_machine_u16_hex for collector-001.elf. Answer shape: lowercase hexadecimal with a 0x prefix, no explanatory text.

Method

  • Artifact is a zip with one member, collector-001.elf (challenge artifact, not published).
  • The answer comes from the ELF header bytes, not from the filename or any note: ELF64 (EI_CLASS=2), little endian (EI_DATA=1), so e_machine is the u16 at offset 0x12, read little endian.
  • Bytes at offset 0x12 give 0x003e (x86-64). Width follows the field type: u16 -> 4 hex digits.
  • Answer: 0x003e.
  • The banked autosolver (challenges/_lib/autosolve_metadata.py, hdr_struct ELF table) derived the same value for all three modes from each attempt's own bytes.
