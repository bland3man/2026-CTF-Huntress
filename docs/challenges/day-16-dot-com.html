Single Solve

Artifact is Morse for hex, hex decodes to "Nice work decoding this warmup! To solve, submit this exact answer to the Game Master: silly-banner-marble-88". Answer: silly-banner-marble-88. GM: CORRECT, flag Tokenea172e810c6e651d9c04b58643c9a340.

Time Trial

Mastery

Zip of 78 blobs, 16 numbered lines each, one fixed encoding per line: base64, rot13, hex, binary, decimal, octal, percent, html entities, json-\u, base32, base64url, reverse, atbash, caesar+7, rot47, and NEW line 16 = Morse spelling hex bytes. The concatenation is the known sentence plus the slug (line boundaries vary per blob, slug straddles lines 13-16). First autosolve failed only because line 16 (morse -> hex) was missing from the ladder. Fix: added LINE_DECODERS["morsehex"] and appended it to LADDER_NAMES in challenges/_lib/autosolve_warmups.py. Offline check: all 78 blobs decode (e.g. blob-01 droll-sunset-maple-64). The GM then reported mastery already solved (reconcile confirmed it). Solver/test: Day 16/Dot Com/scripts/test_mastery.py.
