Task

Determine media.primary_audio_codec_name for audio-001.wav. Artifact: zip with one RIFF/WAVE file.

Solve

  • The actual codec comes from the bytes (fmt chunk format tag 1, 16-bit, mono, 16 kHz), not the name: pcm_s16le (ffprobe codec_name spelling).
  • New extractor challenges/_lib/media_codec.py (ffprobe first, pure-python fmt-tag fallback), registered in autosolve_metadata.py (not found in any source) as media.primary_audio_codec_name (+ a few media.* aliases).
  • Mastery added a filename question with no sibling reference: "exact filename of the renamed evidence-note copy". Fix in autosolve_metadata.answer (reference kept as plain text; not an eligible file type): the renamed copy is the member of the same evidence zip whose SHA-256 equals evidence-note.txt's but under a different name.
