Time Trial and Mastery

The Homebase agent ran both from a script (a_little_based_run.py, saved in the Homebase workspace [local path], not copied here). It used one HTTP session and no hand steps.

  • Mastery (warmups-day-01/mastery) is locked until the Time Trial is done. Starting it first returns HTTP 409 prerequisite_required.
  • Time Trial: start returns attempt_id, download (a capability URL), sha256, answer_ids:["message"] and a server deadline of start+30s. The script downloads, Base64-decodes and submits. Result: CORRECT in 1.363 s. That beat the server deadline but missed the 1 s stated on CourseStack.
  • Mastery: three artifacts (blob-01..03.txt), each with its own capability URL and SHA-256 in the start response, downloaded concurrently. Each blob starts with a numeric index and a tab before the Base64 payload, so strip that prefix before decoding. Answers go under set1.message, set2.message and set3.message. Lessons Learned

  • The static CourseStack download and the Game Master's assigned artifact can differ. Always solve the artifact named in the Game Master start response, and check its SHA-256. The download's "answer slug" was a decoy for this attempt and was marked incorrect.
  • The Game Master's stated answer format ("slug") did not match what it accepted (a flag{} value). Trust the bytes, not the stated format.
  • Homebase uses the proxy http://[ip]/huntress-ctf-proxy (with ?op=list, start, and submit operations). The CourseStack proxy URL works only after you click Connect on the challenge page, which issues the auth token.
