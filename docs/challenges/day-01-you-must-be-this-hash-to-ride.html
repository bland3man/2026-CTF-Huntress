You Must Be This Hash to Ride

Challenge

  • Category: Metadata Forensics (Day 01). Game Master ID metadata-forensics-day-01-hash-to-ride
  • Prompt: "Three ordinary files arrived without trustworthy labels. Build an identity inventory from the bytes themselves and prove which labels can-and cannot-be trusted."
  • Modes: Single Solve (2 pts), Time Trial (1 task, under 4 s, 3 pts), Mastery (2 tasks, under 2 s)

Artifacts

The Game Master assigned a ZIP to each attempt. It was analysed inside AI Homebase and not copied locally. The Single Solve ZIP starts with PK\x03\x04 and contains evidence-note.txt (240 bytes).

Triage

Hash inventory: identify each file from its bytes, then report the filename, size, MD5, SHA-1 and SHA-256 of the file each question names.

Investigation

  • Answer IDs come in groups of five per target file: <target>-filename (exact_text: base name with extension), <target>-size-bytes (integer), <target>-md5, <target>-sha1 and <target>-sha256 (hex, case-insensitive).
  • Single Solve target: the first evidence note. Time Trial target: the roster (roster.csv). Mastery set 1: the renamed copy of the evidence note.
  • The Homebase agent's runner hash_to_ride_runner.py (in [local path]) does start, capability download, ZIP read, identify, hash and submit, all in one HTTP session.
  • Failed path: the first Time Trial and Mastery submissions were wrong because the filename parser returned only the extension (csv). After fixing the filename choice, both returned CORRECT.

Minimal Reproduction

In Homebase, fetch the assigned ZIP through http://[ip]/huntress-ctf-proxy, open the target member, and submit its base name, size, MD5, SHA-1 and SHA-256 under the answer_ids from the start response.

Lessons Learned

  • In timed modes the target file changes from attempt to attempt (note, roster, renamed copy). Map each question's text to its target dynamically instead of hard-coding it.
  • "Filename" means the full base name including the extension. Test the parser against a filename question before the timed run.
