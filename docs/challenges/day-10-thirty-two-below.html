Correction to the first draft of this writeup

This file originally recorded Time Trial / Mastery as blocked by a "server-side gate", because the first start returned 409 timed_intent_not_available. That was never a gate: on a LEGACY single-pool timed route the GM rejects the run_for_time property outright (true OR false), while a plain op=start with the property omitted opens a normal, hall_of_fame_eligible attempt. Both modes were in fact solved by the same unchanged adapter two minutes later. Root cause + the permanent fix (in ctf_gm.GM.start and autosolve_script.start, with regression cases in _test_rotation_fix.py) are written up in challenges/Day 10/Bind Over Matter/Bind_Over_Matter_Writeup.md - that lane was the one that stayed stuck on it for ~4 hours.
