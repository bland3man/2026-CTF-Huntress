BOM Voyage

Lane: Metadata Forensics (Day 03). GM id metadata-forensics-day-03-bom-voyage.

Challenge

Text export files "look identical in an editor but behave differently in scripts." Each answer is text.utf8_bom_present (enum true/false) for a file inside the assigned zip.

Investigation

  • Answer is a pure function of the file's first 3 bytes: EF BB BF -> true, else false.
  • Single Solve and Time Trial: one zip, one file; false accepted both times (roster/evidence-note had no BOM).
  • Mastery: two zips; the questions text (file names, ids) is a DECOY - use answer_ids (setN.<id>) and map set N to download N-1. set1 file started with BOM (true), set2 did not (false).
  • Gotchas: pyzipper absent on VM (zips are plain deflate; use zipfile); Mastery deadline is short, so run start->download->submit in one script (solve_mastery.py).

Lessons

Trust answer_ids over questions text in Mastery; check magic bytes directly.
