Lessons to carry forward

  1. Day 21 = carrier, not language - fifth consecutive confirmation of the D8+ hypothesis. GitHub Actions workflow YAML joins PHP polyglot, stager graph and WMI MOF as a host container around the unchanged descriptor. The lane's carrier universe should now list .yml/.yaml CI/CD workflow (GitHub Actions, T1053-adjacent CI persistence) as SEEN and handled by the generic path.
  2. The pre-brief "no extractor" gap report over-reports. It checks named extractors only. When the missing ids are plain Material_/Codec_ fixtures (here: 100 bash-advanced ids), the generic reader already covers them - verify against the generic path before building anything.
  3. Prompt-to-field mapping is reliable. "Who can trigger it / which runner inherits trust" -> host-profile and stage-profile; "the job that keeps coming back" -> persistence_descriptor role; "static handoff into the next language" -> next-language. Reading the GM's prose first saved a schema hunt.
  4. The readiness gate works as designed. A live-CORRECT prior mode on the same challenge is the strongest possible proof that the same compute will finish inside the window; taking the EARLY path on that basis produced two ranked 4-9 s solves with zero variants spent.
