Two of a Kind

Warmups SSTTMM Modes reported CORRECT in this write-up

Challenge

  • Lane: Warmups (Day 04), GM id warmups-day-04
  • Prompt: "There are only two sides to this story."
  • Question: decode the assigned blob completely; submit the slug the final non-empty decoded line instructs (three lowercase words + two digits).
  • Modes: Single Solve and Time Trial were already done by another agent; this write-up covers Mastery (18 blobs, set1..set18.message).

Triage

Warmup decode family (KB: warmup_decode). Single Solve artifact was one line of space-separated 8-bit binary decoding to Nice work decoding this warmup! To solve, submit this exact answer to the Game Master: <slug>.

Investigation

  1. board.py next 4 commander claimed the unowned challenge; board.py todo showed only Mastery left.
  2. First Mastery start: 429 rate limits on download, and the attempt window was only 7 seconds, so it expired. The saved blobs served as the free lab.
  3. Mastery blobs differ from the Single Solve: each is four NN<TAB>fragment lines, each fragment in a different encoding (01 base64, 02 ROT13, 03 hex, 04 8-bit binary). Fragment boundaries shift per blob. Decoding each line by charset and concatenating in line order gives the full sentence; the slug is on the last line.
  4. Offline solver reproduced 18/18 slugs on the saved blobs, then one automated shot (start -> download -> decode -> submit) returned CORRECT in 6.1 s.

Lessons Learned

  • Mastery windows can be seconds long: never experiment on a timed attempt; reproduce offline on saved blobs first.
  • GM() shares one HTTP connection and is not thread-safe: download sequentially; retry 429 with backoff.
  • Do not assume the Single Solve format carries over; Mastery changed the blob structure.
