Rust Belt (Day 05) - binary-reverse-engineering

Family: dual_format_re (same generator as Day03 Table Manners / Day04 Go Fish). 40-field forensic inventory across 5 deliverables. Solved with scripts/solve_rb.py (adapted from Day03 solve_tm.py (not found in any source)).

Deliverables (per attempt zip, AES pw infected)

  • d01 *.elf ELF x86-64 EXEC little-endian inventory. Labels: elf_class ELF64, machine x86-64, elf_type ET_EXEC, endianness little. section_names/symbols = compact JSON arrays parsed directly from the section header string table and symtab (in file order). disassembly = ["mov eax, <imm>","ret"] from the recover_code function (b8 <imm32> c3); imm was 8100 (0x1fa4). Marker section .huntress = BR01-CATALOG-000 (not a scored field here).
  • d02 *.elf ELF with embedded HCFG config blob. format elf.
  • d03 *.dll + *.runtimeconfig.json .NET PE32 (Mono/.Net, i386). format pe_cli, machine i386, metadata_version v4.0.30319 (reference kept as plain text; not an eligible file type) (from BSJB stream). Config (campaign/domain/mutex) is single-byte-XOR JSON inside the dll, located by brute-forcing the XOR of {"campaign".
  • d04/d05 large *.elf ELF x86-64 with HCFG config. architecture x86-64, format elf. d05 is ~4 MB.

HCFG layout

HCFG magic + version byte + 1-byte XOR key (offset +5) + LE u16 length (+6) + LE u32 crc32 (+8) + single-byte-XOR payload (+12). Decode = XOR payload with key, zlib.crc32 must match. crc32_hex reported as 0x%08x, xor_key_hex as 0x%02x.

GOTCHA (cost me 3 mastery attempts before the fix stuck across mutations): large ELFs contain MULTIPLE HCFG byte matches (decoys / false hits). Do not take the first data.find(b"HCFG") - scan every occurrence and keep the one whose payload both CRC-validates AND json-parses. d05 single-solve: real blob at offset 355376 (key 0x61), decoys at 27634 and 355263.

Answer-shape labels (grader-faithful, short forms)

elf_class ELF64, machine x86-64, elf_type ET_EXEC, endianness little, format elf / pe_cli, machine(.NET) i386, architecture x86-64. JSON arrays compact (separators=(",",":")). Hex lowercase with 0x prefix.

Mastery

80 answer_ids = 2 sets (set1./set2.), 2 artifact zips (one per set), each the same 5-deliverable layout with mutated variant indices. compute() maps setN.<id> to sets[N-1]. Every value derived from that attempt's own bytes.

The "Rust Belt" prompt theme (Rust mangled symbols / panic strings) is flavor; the d01 binary is a plain C runtime (crt1.o / __libc_start_main / variant-NNN.c symbols). Inventory logic is identical to the C++/Go variants of this family.
