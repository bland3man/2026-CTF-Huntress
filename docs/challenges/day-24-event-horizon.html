Method

Solved by the banked metadata-forensics lane autosolver (autosolve_metadata, capability layer), run as autosolve.py 24 metadata-forensics-day-24-event-horizon metadata-forensics. It derives each answer from the attempt's own artifact bytes (file metadata fields such as ZIP EOCD entry counts, PE entry-point RVA / original filename, LNK target path, evidence-note copy filename / size), then submits once per mode under the GM's answer ids.

I did not hand-analyse the artifact this run, so I have no per-field derivation to add here.
