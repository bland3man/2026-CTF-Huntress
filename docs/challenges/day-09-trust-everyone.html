Trust Everyone

Challenge

  • Category: Mobile / Android (Day 09). Game Master ID mobile-android-day-09-trust-everyone.
  • Prompt: "Exploit a challenge CA accepted by a permissive trust implementation."
  • Modes: Single Solve, Time Trial, Mastery - all CORRECT (3/3).
  • Answer form: one field, answer, derived from the assigned APK's own bytes.

Artifacts

  • The assigned APK for this attempt (dynamic per attempt; analysed from its own bytes, not reused across attempts).

Triage

Android-puzzle family: the APK ships a permissive certificate-trust implementation (a custom TrustManager/network-security-config that accepts a challenge-planted CA). The answer is recovered from the APK's bundled trust material / puzzle asset, not by running the app.

Investigation

Solved by the generic adapter challenges/_lib/autosolve_mobile.py at claim: it unpacks the APK, reads the embedded puzzle/trust asset, and applies the family's codecs (the same caesar/xor/split decoders that have resolved the mobile lane D01-D08) to produce the single answer value. No device or dynamic execution.
