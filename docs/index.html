Headline lessons LOG // DEBRIEF

  1. 01
    First contact is the speed.

    When a lane's deterministic solver already knew the day's shape, a mode landed in one to three seconds. When it did not, the same mode cost an agent anywhere from seconds to half an hour. Almost every speed gain came from raising the share of modes the solver handled on first contact.

  2. 02
    Every lane was yesterday plus one layer.

    The daily challenges in a lane shared a spine and added one new container, encoding or language each day. Once we wrote that down as data and predicted the next layer, we could prebuild for it the night before instead of meeting it cold at release.

  3. 03
    Exact strings, no partial feedback.

    The grader compares exact text and rejects a whole batch if one field is off, without saying which. Banking every accepted value and format (hex width, casing, braces) turned a guessing game into a lookup.

  4. 04
    A thirty-second window forgives nothing.

    On Day 11 the release-time rate limiting made our retry backoff sleep straight through a timed window, and a lost Time Trial also locked the Mastery behind it. Afterwards every timed start became a hard time budget, preceded by a free status check of how many attempts remained.

  5. 05
    Derive from this attempt's bytes.

    Timed material rotated per attempt. Reusing an old answer was never safe; only a solver that read the current artifact was.

  6. 06
    One owner per mode.

    With two stations and shared attempts, two runners on one mode could burn a scarce ranked attempt. Atomic claims and static lane ownership kept that from happening.

  7. 07
    A model in the hot path sets a floor.

    Each agent decision is a model turn. The fastest teams cleared a full day in minutes with plain scripts dispatching to solvers; our agents were best used for triage and for extending solvers, not for executing every step. A full reverse-engineering special (Day 30) was a different class entirely: hours, not seconds.
