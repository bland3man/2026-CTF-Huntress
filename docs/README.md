# 2026-CTF-Huntress

Team write-ups from **Huntress CTF 2026** (October 1-31, 2026; final placement 38th), published as a static site.

Pages site: https://bland3man.github.io/2026-CTF-Huntress/

## What is here

- 189 challenge write-ups, written during the event, one page each, grouped by day (31 of 31 days logged) and by lane
  (warmups, metadata forensics, mobile, script analysis, binary reverse engineering, web, other).
- How the team was set up: an AI Commander per station, lane agents, deterministic per-lane solvers and a daily learning loop.
- The Game Master contract: what each mode (Single Solve, Time Trial, Mastery) asked for, with invented example values.

Flags shown are the team's own per-team dynamic values from the event.
No challenge files, binaries or archives are included; only rendered text.

## How to view

- Online: open the Pages site above.
- Locally: open `index.html` in any browser. All links are relative, so it also works straight from disk.

233 HTML pages, plain HTML/CSS with a small optional script for search and copy buttons. Everything works without JavaScript.
