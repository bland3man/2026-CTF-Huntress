By the Numbers (Warmups, Day 05)

Challenge

  • Category: Warmups (Day 05), GM id warmups-day-05
  • Prompt: "These characters have been reduced to numbers."
  • Question: Decode the assigned blob completely. What exact answer slug does its final non-empty decoded line instruct you to submit? (answer_format.kind = pattern: three lowercase words separated by hyphens, followed by a hyphen and a two-digit number; submit the slug only)
  • This is a recurring "Warmup decode" family (seen Day 01 "A Little Based", Day 02 "Half a Turn", Day 03 "Hex Appeal"): the challenge title/prompt is itself a pun naming the encoding layer, and the final non-empty decoded line tells you exactly what to submit.

Artifacts

  • blob.txt (395 bytes) - a single artifact, space-separated ASCII text

Triage

The prompt "characters have been reduced to numbers" directly names the encoding: each character of the message is represented as its decimal ASCII code, space-separated.

Investigation

  1. Read the artifact as text; split on whitespace to get a list of decimal number strings.
  2. Convert each number to its character via chr(int(n)) and join.
  3. Decoded output (verified directly from the artifact bytes): 
    Nice work decoding this warmup! To solve, submit this exact answer to the Game Master:
sturdy-river-grove-57
  4. The final non-empty line instructs the exact slug to submit, matching the required three-lowercase-words-NN pattern.

Flag Recovery

Decimal-byte decode of blob.txt -> final instruction line -> answer slug: **sturdy-river-grove-57** (this Single Solve sample's value; Time Trial and Mastery assign a freshly mutated blob per attempt, so the slug differs per attempt and must be re-derived from that attempt's own bytes using the identical decode).

Minimal Reproduction

data = open('blob.txt', 'rb').read()
nums = data.decode().split()
decoded = ''.join(chr(int(n)) for n in nums)
print(decoded)  # last line = answer slug

A general-purpose automated version that also handles related warmup variants (hex, base64, rot13, binary, chained encodings) is banked at challenges/_lib/decode_chain.py.

Lessons Learned

  • "Warmup decode" is a stable recurring family across the event (Days 01-05 so far): the title/prompt names the encoding, and the LAST non-empty decoded line is always the literal submission instruction - don't overthink these, they resolve in under a minute with the banked decode_chain.py.
  • Process gap: this solve's script was saved under Day 05/Backup Spill/scripts/ as solve_by_numbers.py even though the challenge is actually Warmups (GM id warmups-day-05), not a Backup Spill submode - likely because both were being worked in the same session. Future agents should save each solver under its own actual challenge's folder (matching the real GM id, not a thematically-similar neighboring directory) so writeups and solvers stay correctly paired.
