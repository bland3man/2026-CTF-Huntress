Day 27 - Monkey Business (warmups-day-27) - agent-3

Prompt: "Ook. Ook? Ook! Someone seems chatty." -> the Ook! esoteric language (a brainfuck skin).

Method

Ook tokens (Ook. / Ook? / Ook!) are read in PAIRS and map 1:1 onto brainfuck: .?=> ?.=< ..=+ !!=- !.=. .!=, !?=[ ?!=]. The Single blob (33929 bytes) held only Ook. and Ook! (3393 pairs: 1667 +, 1618 -, 108 .), so no loops. Running the program yields: "Nice work decoding this warmup! To solve, submit this exact answer to the Game Master: hearty-castle-fern-71"

Results

  • Single Solve: hearty-castle-fern-71 - CORRECT
  • Time Trial: CORRECT (3.4 s, via autosolve, same Ook decoder on the attempt's own blob)
  • Mastery: CORRECT (133-member zip of numbered multi-codec fragment blobs; fragment line 27 of each member is an Ook line, line 26 is plain brainfuck). 133/133 blobs validated offline against the known sentence before submit.

challenges/Day 27/Monkey Business/scripts/solve.py: added _ook() (pair mapping + existing bounded _brainfuck), a pure-Ook branch at the top of decode_blob, and an ook candidate in the per-fragment decoder list.
