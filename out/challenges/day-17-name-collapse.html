Name Collapse (mobile-android, Day 17)

GM id: mobile-android-day-17-name-collapse. Case MOB-17-7A748BA6F3, package com.huntress.mobile.d17.v7a748ba6f308.

Result

Single, Time Trial and Mastery all CORRECT via autosolve (Single 1.1s, TT 3.5s, Mastery 2.6s). Single answer (decoded from the shipped APK): AnswerANS-E26A5C21D3110FA1

Mechanism

assets/huntress_puzzle.json in the APK: {"codec":"indexed","data":"-2FE1A2D163AA1N51SC0","order":[3,10,17,4,11,18,5,12,19,6,13,0,7,14,1,8,15,2,9,16]}. New codec "indexed" = a permutation: character i of data goes to position order[i] (scatter). The result starts with ANS-, which confirms the direction. The inverse (gather) direction does not give the ANS- prefix.

Fix

Added _indexed decoder (aliases index/permute/permuted/scatter) to challenges/_lib/autosolve_mobile.py. It validates that order is a permutation, and returns whichever of scatter/gather matches ANS-<16 hex>.

Notes

Mastery was recorded by the tool as a RANKED attempt (autosolve chose it); I did not start any timed mode by hand.
